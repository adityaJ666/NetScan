\# NetScan



\### Network Security Scanner



NetScan is a Python-based network security scanner with a professional graphical interface built using PySide6.



It allows authorized users to scan TCP ports, identify common services, store scan history, and generate security reports.



\---



\## Features



\- TCP port scanning

\- IP address resolution

\- Common service identification

\- Custom port ranges

\- Background scanning using QThread

\- Professional PySide6 GUI

\- Scan history

\- JSON-based local storage

\- Security report generation

\- TXT report export

\- Dashboard statistics

\- Settings and About sections



\---



\## Technology Stack



\- Python

\- PySide6

\- Socket Programming

\- JSON

\- QThread

\- Git \& GitHub
